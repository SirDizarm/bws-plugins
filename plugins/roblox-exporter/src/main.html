Roblox Exporter

One ZIP containing a separate OBJ for every mesh, your model hierarchy, textures, and Roblox Studio assembly scripts.

OBJ parts use Roblox stud units. 1 stud = 0.28 metres.

  1. Choose Send current model above to share a copy of every mesh, including hidden parts, its group hierarchy and texture library.
  2. Build the ZIP below, then choose Download ZIP above.
  3. Import the OBJ files as separate MeshParts in Roblox Studio. Use the included setup script or rebuild plugin to assemble the parts.

Your BWS workspace is not changed. Send the model again if you edit it.
