Roblox Exporter

For the new BoltWorks Studio: BWS 50+

These plugins are for the new BWS 50+ plugin system, not the legacy edition (49.x or earlier). Check each plugin for its minimum required 50.x version.

Visit BoltWorks Studio

Optional BWS plugin. Export your model as one ZIP with separate OBJ mesh parts, textures, a hierarchy manifest, and Roblox Studio assembly scripts.

1 stud = 0.28 metres. Part geometry is centered individually; the assembly scripts restore placement and hierarchy.

Download plugin 1.1.0

Install and use

Use BWS 50.0.12 or later (plugin API 2). Choose Install from file in Plugins, review the permissions, then enable Roblox Exporter. It is off by default.

Open the plugin or choose Export Roblox Pack. Choose Send current model, Build Roblox ZIP, then Download ZIP. Import the separate OBJ files in Roblox Studio and use the included assembly script or rebuild plugin.

Privacy and permissions

Runs in an isolated workspace without network or filesystem access. Only receives your model and texture library when you choose to share them. Cannot edit your project. BWS saves the returned ZIP only when you click Download ZIP.
