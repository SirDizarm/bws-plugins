BWS AI Modeling

For BoltWorks 3D Studio v50.0.57 or later

This optional plugin provides the AI-facing BoltWorksConnect modeling tool catalog. It is not built into the editor.

Open BoltWorks 3D Studio

Download BWS AI Modeling 1.0.3

Installation

Install plugin.bwsplugin through BWS Plugins, review its AI edit permissions, then enable it. Pair BoltWorksConnect from your AI client after enabling the plugin.

Fusion safety

AI shell fusion is queued in the background and returns an operation ID immediately. Poll bws_get_operation until completion. Each call is limited to 8 source objects and 40,000 total source triangles; larger models must be fused in staged groups.

Permissions

The package is declarative. It contributes tool names and validated mappings to BWS operations; it contains no downloaded executable workspace.
