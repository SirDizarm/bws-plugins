# Extraction status

The interactive graph editor, master graph generator and House Batch runtime are packaged in the separate plugin. BWS keeps graph persistence, validation and scene-shared construction/math functions. It does not load the plugin until installed and enabled.

API 4 exchanges graph JSON, validated mesh parts, bounded texture data and explicit graph downloads. No plugin code executes in the BWS window. Existing graph output replacement needs confirmation. Scene Studio node-based nature generation now awaits the plugin preview bridge.

Status: implemented local preview, not a validated release. See README for current limitations and pending checks.
