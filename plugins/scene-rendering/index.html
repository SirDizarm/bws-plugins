Light a static copy of your model with adjustable main and mirror lamps, light guides and fullscreen preview.

Download version 1.2.0

Rundown preview

Select parts by clicking or using the searchable list. The condition slider adds weathering, loosening, dropped pieces and reversible gaps. Restore selected parts or reset all damage. Fire placement and exporting damaged scenes are not included yet.

Install and use

Use BWS 50.0.14 or later. Install and enable the plugin, then open it from Plugins or Scenes. Choose Send current model to share a copy. No model is shared automatically.

Scope and permissions

Your editor lighting stays unchanged. This is separate from Scene Studio. Supports base colors and named image textures; animated rigs, normal maps and custom shaders are not transferred. No direct editor, filesystem or network access.
