Fireplace

An optional, experimental fireplace scene with mesh logs, adjustable fire audio and fullscreen viewing.

Download Fireplace 0.1.0

Installation

Install the package in BWS Plugins, then enable it. Find Fireplace in the Scenes toolbar. Use BWS 50.0.12 or later for improved plugin storage.

Permissions

Runs in an isolated workspace without editor, filesystem or network access. Fullscreen starts only when you choose it. Custom model transfer is not implemented.

Updates

0.1.0: Initial experimental scene viewer. Visual improvements are on hold while BWS plugin extraction continues.
