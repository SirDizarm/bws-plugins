Image to Mesh

Turn height images and reference sheets into an editable model. Includes Hybrid, Recovered V30, detailed human and visual-hull reconstruction modes.

Download 1.1.0

Use in BWS

Requires BWS 50.0.13 or later. Install, enable and Open. Load an image, choose settings and Create image mesh. Inspect the 3D preview, then choose Add mesh to BWS. Existing scene objects are retained.

Permissions

The plugin reads only the image you choose or an explicitly requested AI generation input. It cannot read your project, access the network, or directly change the editor. BWS validates the returned mesh before insertion.
