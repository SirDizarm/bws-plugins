BWS Plugins

For BoltWorks 3D Studio: BWS v50+

These plugins are only for the new BoltWorks 3D Studio v50+ plugin system, not the legacy edition (v49+). Check each plugin for its minimum required 50.x version.

Open BoltWorks 3D Studio

Install only the tools you want. Plugins are off by default after installation; enable them in BWS when you are ready.

Scene Rendering

Version 1.2.0: model-copy lighting, part selection, reversible rundown preview and fullscreen. Requires BWS 50.0.14.

Image to Mesh

Height-image and reference-sheet reconstruction with a 3D preview. Requires BWS 50.0.13. Installation and plugin-window checks passed; generation and AI integration testing pending.

Roblox Exporter

OBJ parts, textures, hierarchy and Roblox assembly scripts in one ZIP. Development preview, requires BWS 50.0.10. Testing pending.

Fireplace

Experimental isolated fireplace scene with adjustable fire audio and fullscreen viewing. Version 0.1.0.
